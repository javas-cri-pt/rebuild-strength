# Rebuild Strength

A **training-log PWA** for strength programs. Log your sessions, edit the program with local overrides,
swap an exercise (just-for-today or always), track warm-ups separately from working sets, and export a
**Markdown coach report** with session-to-session deltas.

**Live → https://javas-cri-pt.github.io/rebuild-strength/**

Local-first and offline (service worker); your data stays in your browser.
